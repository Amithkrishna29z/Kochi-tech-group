# Kochi Tech Group — Study Content

A collection of self-study learning resources distilled from practitioner roundtables.

## Modules

- **[A Developer's Guide to Quality Assurance & Testing](Quality%20assurance/qa-testing-study/README.md)** — shift-left development, unit/API/integration/UI testing, TDD & BDD, static analysis, UAT, and the full release & post-release testing landscape (load, stress, spike, breakpoint, soak). Includes a glossary, a debates file capturing genuine practitioner disagreements, and a quick-reference cheat sheet.

- **[Why C# and Java Developers Can't Write Low-Level Software](Why%20C%23%20and%20Java%20developers%20can't%20write%20low%20level%20software/study-content/01-structured-notes.md)** — the C abstract machine, the three design models, JIT vs AOT, code labs, flashcards, and a quiz.
